# Оживление планшета (Acer Iconia Tab W501)

Этап 0. Сейчас на планшете нерабочая Ubuntu — ставим систему заново.

## Характеристики

| Параметр | Значение |
|---|---|
| Модель | Acer Iconia Tab W501 (Model No. V1JB1) |
| CPU | AMD C-50, 2 ядра × 1.0 ГГц, Radeon HD 6250 |
| RAM | 2 ГБ |
| Диск | 32 ГБ SSD |
| Экран | 10.1", 1280×800, ёмкостный мультитач |
| Порты | USB 2.0 ×2, HDMI, Wi-Fi, Bluetooth |
| Прошивка | Legacy BIOS (не UEFI) |

## Что понадобится

- USB-флешка **≥ 8 ГБ**;
- образ Linux (см. ниже);
- программа записи: **Ventoy**, **Rufus** (Windows) или **balenaEtcher**;
- USB-клавиатура/мышь (для установки), при необходимости USB-хаб (портов всего два);
- зарядное устройство планшета.

## Выбор дистрибутива

При 2 ГБ RAM тяжёлые окружения (GNOME/KDE) не нужны.

| Вариант | Комментарий |
|---|---|
| **Lubuntu 24.04** (LXQt) | простой старт, лёгкий |
| **Debian 12 + LXQt** | больше контроля, стабильно |
| **MX Linux** (XFCE) | хорош для старого железа |
| antiX | если совсем медленно |

- C-50 поддерживает x86-64 → берём **amd64**. Если Live-USB не грузится — попробовать Debian **i386**.
- Для режима «панели»: минимальный Debian + Chromium.

## Запись образа

1. Скачать ISO нужного дистрибутива.
2. Записать:
   - **Ventoy** — просто скопировать ISO на флешку;
   - **Rufus** — режим GPT/MBR под Legacy BIOS;
   - **balenaEtcher** — «просто записать».
3. Дождаться завершения записи.

## Загрузка с флешки

1. Вставить флешку, включить планшет.
2. Войти в boot menu: обычно **F12** (BIOS — **F2**). Если не срабатывает — проверить клавиши в мануале W501.
3. Выбрать USB-устройство.
4. Если флешки нет в списке — в BIOS включить загрузку с USB / Legacy.

## Live-тест (до установки!)

Обязательно проверить на Live-системе:

- [ ] **тач** — палец двигает курсор; проверить `xinput` / `libinput list-devices`;
- [ ] **Wi-Fi** — видит сети и подключается;
- [ ] **звук** — динамики/наушники;
- [ ] **яркость** — регулируется;
- [ ] **USB** — флешка/хаб определяются;
- [ ] **аккумулятор** — держит ли заряд (может быть мёртв).

Если что-то ключевое не работает — не устанавливать, сначала решить (другой дистрибутив/ядро) или принять ограничение.

## Установка

1. Запустить установщик с рабочего стола Live-системы.
2. **Стереть диск** (32 ГБ SSD), разметка автоматически.
3. Файловая система — **ext4**.
4. Swap: 2 ГБ на диске **или** zram-своп.
5. Создать пользователя и пароль.
6. Загрузчик GRUB — на диск.

## После установки

- [ ] обновить систему (`apt update && apt upgrade`);
- [ ] поставить браузер (Firefox/Chromium);
- [ ] поставить `openssh-server` для удалённого администрирования;
- [ ] включить NTP (синхронизация времени);
- [ ] при желании — автологин;
- [ ] проверить тач после перезагрузки.

### Проверка тача

```bash
libinput list-devices | grep -i -A3 touch
xinput list
dmesg | grep -i -E "touch|input"
```

## Режим панели (опционально)

- **PWA**: в Chromium открыть HA → «Установить приложение» — иконка как у обычного приложения.
- **Киоск**: автозапуск с `chromium --kiosk http://<ip-ha>:8123`.
- Киоск включать только если планшет не нужен для других задач.

## Troubleshooting

| Проблема | Что делать |
|---|---|
| Тач не работает | `lsusb`, `dmesg`, `libinput list-devices`; попробовать другое ядро/дистрибутив |
| Нет Wi-Fi | проверить `lspci`/`lsusb`, поставить firmware (`firmware-brcm80211`, `firmware-atheros`) из non-free |
| Не грузится с USB | Legacy BIOS, другой порт/флешка, пересоздать загрузчик (MBR) |
| Тормозит | LXQt/antiX, отключить эффекты, меньше вкладок |
| Не держит батарею | питание от БП, проверить вздутие аккумулятора |
| Не меняется яркость | проверить управление подсветкой в DE; при необходимости `xbacklight`/`brightnessctl` |

## Заметки

- Планшет старый: после установки не стоит рассчитывать на 1080p-видео в браузере; для видео лучше `mpv`.
- USB не должен уходить в сон — иначе ESP32 (если питается от планшета) будет перезагружаться.
