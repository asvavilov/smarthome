# План

## Цель v1

Минимальная рабочая версия: **планшет показывает данные BME280**, которые собирает **ESP32** и отдаёт в **Home Assistant** через **ESPHome**.

## Этапы

### Этап 0 — Планшет (сейчас)

- [ ] Live-USB тест (тач, Wi-Fi, звук, яркость, батарея);
- [ ] установить лёгкий Linux;
- [ ] проверить работу после установки;
- [ ] браузер + доступ к HA.

**Критерий готовности:** планшет стабильно грузится, тач и Wi-Fi работают, открывается веб-интерфейс HA.

Подробно: [TABLET-LINUX.md](TABLET-LINUX.md).

### Этап 1 — Узел датчиков

- [ ] BME280 подключить к ESP32 по I2C;
- [ ] прошить ESPHome;
- [ ] узел появился в HA;
- [ ] дашборд с температурой/влажностью/давлением.

**Критерий готовности:** HA показывает три величины с регулярным обновлением.

Подробно: [ESP32-BME280.md](ESP32-BME280.md).

### Этап 2 — Терминал

- [ ] HA-дашборд на планшете (PWA или закладка);
- [ ] при желании — киоск-режим и автозапуск.

**Критерий готовности:** после включения планшет сам открывает дашборд (или это одна кнопка).

### Этап 3 — Улица

- [ ] вынести BME280 на улицу: провод + радиационный щиток **или** отдельный Wi-Fi-узел.

**Критерий готовности:** уличные T/H/P в HA.

### Этап 4 — Расширение (опционально)

- реле/актуаторы (свет, вентилятор);
- LoRa-часы T-Watch-S3 Plus как носимый терминал;
- камера (ESP32-CAM);
- CO₂ (MH-Z19), освещённость (ADS1115 + фоторезистор) и т.п.

## Заметки и риски

- Планшет слабый (AMD C-50, 2 ГБ RAM) → только лёгкий дистрибутив (LXQt/XFCE), без тяжёлых вкладок.
- VM Home Assistant в Proxmox должна быть в **bridged-сети**, иначе не работает mDNS/автообнаружение ESPHome.
- Старый аккумулятор планшета может быть мёртв/вздут — питание от БП.
- USB планшета не должен уходить в сон, иначе ESP32 будет терять питание/перезагружаться.
- Для ESP32 лучше статический IP или DHCP-резерв.
