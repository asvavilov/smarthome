# Архитектура

## Схема

```
                    локальная сеть (Wi-Fi / LAN)
   ┌───────────────┐                         ┌──────────────────────────┐
   │     ESP32     │   ESPHome native API    │  Home Assistant          │
   │  (DevKit)     │ ──────────────────────► │  (VM в Proxmox)          │
   │               │        Wi-Fi            │  история, автоматизации  │
   │  BME280       │                         │  веб-дашборд             │
   │  (I2C)        │                         └────────────┬─────────────┘
   └───────────────┘                                      │ HTTP
                                                          ▼
                                              ┌──────────────────────────┐
                                              │  Планшет (Linux)         │
                                              │  браузер: дашборд HA     │
                                              │  10" 1280×800, тач       │
                                              └──────────────────────────┘
```

## Поток данных

1. **BME280 → ESP32**: I2C (SDA/SCL), адрес `0x76`.
2. **ESP32 → Home Assistant**: ESPHome native API по Wi-Fi (или MQTT).
3. **HA → планшет**: обычная веб-страница дашборда в браузере.

Планшет **не связан с ESP32 напрямую**: USB используется только для питания и первичной прошивки. Работа идёт по сети.

## Роли

| Устройство | Что делает | Чего не делает |
|---|---|---|
| ESP32 + BME280 | читает датчик, отдаёт в HA | не рисует UI |
| Home Assistant | хранит историю, автоматизации, отдаёт дашборд | не «владеет» планшетом |
| Планшет | показывает UI, запускает любые приложения | не обязан быть только панелью |

## Сеть

- ESP32 и HA — в одном L2-сегменте.
- В Proxmox у VM HA — **bridged** сеть (не NAT), иначе не работает автообнаружение ESPHome.
- Желателен статический IP/DHCP-резерв для ESP32.
- HA доступен по `http://<ip-vm>:8123`.

## Почему так

- Минимум проводов: датчик рядом с ESP32, связь по Wi-Fi.
- HA уже есть → не нужно писать свой сервер и UI.
- Планшет остаётся обычным компьютером: HA — просто вкладка/приложение.
- Узел датчиков дешёвый и автономный: можно позже вынести на улицу или добавить второй.
